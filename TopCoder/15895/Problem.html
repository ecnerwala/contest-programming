Problem Statement

    

We use the following pseudocode to visit each cell of an N x N x N cube exactly once: 

for sum = 0 .. 3*N-3:
    for x = 0 .. N-1:
        for y = 0 .. N-1:
            for z = 0 .. N-1:
                if x+y+z == sum:
                    visit (x,y,z)

You are given the int N and the long long index: a 0-based index into the sequence of cells visited by the above pseudocode. Return a vector <int> containing the coordinates of that cell.

Definition

    
Class:IterateOverACube
Method:findCell
Parameters:int, long long
Returns:vector <int>
Method signature:vector <int> findCell(int N, long long index)
(be sure your method is public)

Limits

    
Time limit (s):2.000
Memory limit (MB):256

Constraints

-N will be between 1 and 10^6, inclusive.
-index will be between 0 and N^3 - 1, inclusive.
