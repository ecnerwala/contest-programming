Problem Statement

    

You are given an vector <int> A consisting of zeros and ones, and an odd int k. You are allowed to perform operations of the following form:

  • Select a contiguous subarray of A of length exactly k.
  • Replace all the elements in that subarray by the element that appears more often.

Recall that k is odd, so any such operation is always well defined. What is the minimum number of these operations needed to transform A to an vector <int> of the same length consisting of all ones? If there is no way to achieve that, output -1.

Definition

    
Class:UniformingArray
Method:minOperations
Parameters:vector <int>, int
Returns:int
Method signature:int minOperations(vector <int> A, int k)
(be sure your method is public)

Limits

    
Time limit (s):2.000
Memory limit (MB):256

Constraints

-A will contain between 3 and 2,000 elements, inclusive.
-Each element of A will be 0 or 1.
-k will be odd.
-k will be between 3 and |A|, inclusive.
