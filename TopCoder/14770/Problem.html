Problem Statement

    

A word search consists of a rectangular grid of letters. Given a grid, the goal is to find a word, in this case oriented horizontally (left to right) or vertically (top to bottom). The grid of letters is given in vector <string> grid, where each elemnt represents a row of the grid, with row 0 being at the top.

Given a string word to find, how many times does it appear in grid, either horizontally or vertically?

Definition

    
Class:MultiWordSearch
Method:countTimes
Parameters:vector <string>, string
Returns:int
Method signature:int countTimes(vector <string> grid, string word)
(be sure your method is public)

Limits

    
Time limit (s):2.000
Memory limit (MB):256

Constraints

-word will contain between 2 and 50 characters, inclusive.
-Each character of word will be an upper-case letter ('A'-'Z').
-grid will contain between 1 and 50 elements, inclusive.
-Each element of grid will contain between 1 and 50 characters, inclusive.
-All elements of grid will be the same length.
-Each character of each element of grid will be an upper-case letter ('A'-'Z').

Examples

0)
    
{"WORD",
 "ORDW",
 "RDWO",
 "DWOR"}
"WORD"
Returns: 2
The word appears once horizontally and once vertically.
1)
    
{"ABCDE",
 "FGHIJ",
 "KLMNO",
 "PQRST"}
"XYZ"
Returns: 0
The word doesn't appear at all.
2)
    
{"ABA",
 "BAB",
 "ABA"}
"AB"
Returns: 6
There are three horizontal occurrences, and three vertical.
3)
    
{"AAA",
 "AAA",
 "AAA"}
"AA"
Returns: 12
